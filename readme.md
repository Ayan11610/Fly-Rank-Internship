## ⚙️ Getting Started

### 📋 Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm**, **pnpm**, or **yarn**

### 🔧 Setup & Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build the application for production:
   ```bash
   npm run build
   ```
